How it works

And the handful of things worth knowing.

It keeps running when the window is minimized

Timers inside a web page are throttled when its tab is hidden and stop altogether when the window is minimized — which is why most refresh extensions quietly stall. Refresh Radar keeps the countdown in an offscreen document, reloads the tab from the background worker, and runs a once-a-minute sweep as a backstop. Minimize the window, switch desktops, leave it on another monitor: the watch carries on.

A tab Chrome has discarded to save memory is revived by the next scheduled reload, so long watches survive that too.

Limits

  • Content scripts cannot run on chrome:// pages, the Web Store, or other extensions' pages.
  • Change mode needs one reload to establish its baseline, so the first load never alerts.
  • Page scripts are blocked on sites with a strict Content-Security-Policy; everything else keeps working there.
  • Form restore deliberately skips password, file and hidden inputs.
  • Nothing leaves your machine unless you set a webhook yourself.
